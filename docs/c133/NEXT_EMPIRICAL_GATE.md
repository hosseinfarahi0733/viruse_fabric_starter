# Next empirical gate — preregistration only

C133 does not fit biological data. The next authorized action is a public-data
audit and preregistration for coarse host-response trajectories.

Required before fitting:

1. freeze operational meanings of `X1`, `X2`, `X3` and outcome `Y`;
2. count independent subjects/studies, missing timepoints and outcome balance;
3. define leave-one-study-out splits;
4. preregister single-time, concatenated, pairwise, state-space and low-rank
   tensor baselines;
5. preregister time permutation, outcome shuffle and pairwise-null controls;
6. define effect-size, calibration, uncertainty and replication gates;
7. prohibit outcome-informed window and feature redefinition;
8. remain at coarse public host-response level.

Kill the biological branch if the three-layer model does not improve held-out
performance over capacity-matched pairwise/tensor baselines, if its advantage
survives time permutation, or if external replication fails.
